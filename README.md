# CAA-project
CAA900 project
AWS Serverless Cloud Application (Terraform & CI/CD)
• Designed and deployed a serverless e-commerce application on AWS using Lambda, API Gateway, DynamoDB, S3, IAM, and Cognito.
• Built REST APIs using AWS Lambda and API Gateway for core application functions.
• Implemented authentication and authorization using Amazon Cognito and IAM.
• Designed a scalable DynamoDB data model for transactional workloads.
• Deployed frontend using Amazon S3 static hosting.
• Applied Terraform for Infrastructure as Code (IaC) to provision AWS resources.
• Used Git and CI/CD practices to support automated deployment workflows.
