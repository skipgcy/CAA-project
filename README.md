# CAA-project
CAA900 project
AWS Serverless Cloud Application (Terraform & CI/CD)
1. Designed and deployed a serverless e-commerce application on AWS using Lambda, API Gateway, DynamoDB, S3, IAM, and Cognito.
2. Built REST APIs using AWS Lambda and API Gateway for core application functions.
3. Implemented authentication and authorization using Amazon Cognito and IAM.
4. Designed a scalable DynamoDB data model for transactional workloads.
5. Deployed frontend using Amazon S3 static hosting.
6. Applied Terraform for Infrastructure as Code (IaC) to provision AWS resources.
7. Used Git and CI/CD practices to support automated deployment workflows.
